✨ Gold Rush Landing Page ✨

A premium landing page for Gold Rush Jewellery Management Software, built with ReactJS (Vite) for the frontend and ExpressJS for the backend.

📁 Project Structure

client/: ReactJS Frontend (Vite)

server/: ExpressJS Backend

✅ Prerequisites

Node.js installed (LTS recommended)

🚀 How to Run

Follow these steps to set up and run the application:

1. Start the Backend Server (ExpressJS)

Open your first terminal window.

Navigate to the server directory:

cd server


Install necessary dependencies (if not already done):

npm install


Start the Express server:

npm start


The server will run on http://localhost:5000.

2. Start the Frontend Client (ReactJS)

Open a new terminal window.

Navigate to the client directory:

cd client


Install necessary dependencies (if not already done):

npm install


Start the development server (Vite):

npm run dev


Open the displayed URL in your browser (usually http://localhost:5173) to view the application.

🌟 Features

Rich Aesthetics: Premium gold and dark theme with stunning glassmorphism effects.

Responsive Design: Fully responsive layout ensures a seamless experience on all devices.

Mock Data Integration: Blog posts are dynamically fetched from the dedicated backend API.

Contact Form: Submissions are successfully sent to the backend and logged to the console for review.
